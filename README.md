# DreamPSX
PlayStation emulator research and development for Sega Dreamcast.

## Development status
Experimental project. The host-side CMake build and all 13 CTest targets passed in GitHub Actions on commit `e5d0b8db2f9556c2d5aa5b45b53d22732ec6890e`. This validates the host test suite only; the Dreamcast/KallistiOS target remains a separate future integration step.

## Target
Sega Dreamcast with 16 MiB RAM. Long-term target: CDI test build for Flycast, then GDEMU.

## Limitations
No Dreamcast/KallistiOS build, CDI image or playable game exists yet. CPU registers and BIOS instruction fetch are represented, and a growing subset of R3000A instructions plus the first GTE geometry commands (NCLIP, MVMVA, RTPS, RTPT, AVSZ3, AVSZ4, SQR, OP, GPF, GPL, NCS and NCCS initial implementations) execute; instruction decoding/execution remains partial, and the GPU now has a host-side VRAM/fill-rectangle core connected to GP0/GP1 MMIO, with external VRAM backing storage; the GPU now supports initial GP0 flat-shaded triangle rasterization and A0/C0 image transfers through GPUREAD; exact shared-edge rules, draw-mode, texture window, textured and Gouraud polygons, blending, display output, DMA, CD-ROM, timers and other hardware devices remain incomplete; GP0(E3h-E5h) drawing area and offset state now clips and translates flat triangles. The host CMake/CTest suite passes in GitHub Actions, but it does not produce a Dreamcast binary or CDI image.
