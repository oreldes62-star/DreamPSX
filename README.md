# DreamPSX
PlayStation emulator for Sega Dreamcast.

## Development status
The repository currently contains the initial memory-bus and interrupt-controller architecture specification. This is a design document, not an implemented or playable emulator build.

## Architecture
- [PS1 memory bus and interrupt design](docs/PSX-MEMORY-BUS-DESIGN.md)

Target: Sega Dreamcast (16 MiB RAM), with a future CDI test build for Flycast and GDEMU.
